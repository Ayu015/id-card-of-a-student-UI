# Student ID Card UI

A simple and visually designed **Student Identity Card UI** for a school. This project demonstrates a digital student ID card layout with school branding, student photograph, personal details, and principal signature.

## 📸 Project Preview

The ID card design includes:
- School name and contact information
- School logo
- Student photograph
- Student name and class
- Admission number and gender
- Father's name
- Phone number and address
- Principal's signature

## ✨ Features

- Clean and structured ID card layout
- School branding with logo and header
- Student profile photo section
- Organized student information
- Decorative background design
- Simple and readable interface

## 🛠️ Technologies Used

- HTML5
- CSS3
